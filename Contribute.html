Contribution Workflow

Follow these simple steps to contribute your UI components.

Fork the Repository

Create your own copy of the UIverse repository on GitHub.

Clone the Project

Download your fork locally using Git and start development.

Add Your Component

Build reusable UI components using HTML, CSS, and JavaScript.

Follow Project Structure

Use clean class names, responsive layouts, and readable code.

Commit & Push

Save your changes and push your branch to GitHub.

Create Pull Request

Submit your pull request so maintainers can review your work.

Contribution Guidelines

Keep the project clean, modern, and beginner-friendly.

Write clean and readable code
Make all components responsive
Add comments where necessary
Avoid unnecessary libraries
Maintain modern UI consistency
Create reusable components
