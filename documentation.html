🎨 Customization

Customize colors, shadows, radius, and typography using CSS variables.

CSS Variables 
:root {
  --primary: #7c3aed;
  --secondary: #6366f1;

  --bg-dark: #0f172a;
  --text-light: #f8fafc;

  --radius: 18px;
}
